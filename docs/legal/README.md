## Enable GitHub Pages (one-time)

1. Open https://github.com/samithaheem9431/PakFasal/settings/pages
2. **Build and deployment → Source**: Deploy from a branch
3. Branch: `main` · Folder: `/docs` · **Save**
4. Wait 1–2 minutes, then open the Privacy URL in a browser

## App config

Defaults already point at these GitHub Pages URLs (`PRIVACY_POLICY_URL` / `ACCOUNT_DELETION_URL`).
